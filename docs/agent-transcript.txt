GOAL
A merchant-dashboard page to create payment links, list them and filter them by status. Data is
in memory or mocked, with no backend.

REQUIREMENTS (normalised from the brief)
1. Create form
   - Amount (₹): required, > 0, at most 2 decimals, at most ₹5,00,000. Store as integer paise and
     never use float maths.
   - Description: required, trimmed, at most 100 characters.
   - Customer: at least one of email or phone. Validate the format of whichever is given (Indian
     mobile number, optional +91).
   - Expiry date: optional. If given, it must be in the future at submit time.
2. List: amount, description, customer, status (Active / Paid / Expired) and created time. A link
   whose expiry has passed shows Expired. Status is derived from `now`, never stored.
3. Filter: All / Active / Paid / Expired.
4. States: empty (per filter), loading, error with retry, and inline validation errors linked with
   aria-describedby.
5. Fully keyboard-accessible, with no horizontal scroll at 375px.
